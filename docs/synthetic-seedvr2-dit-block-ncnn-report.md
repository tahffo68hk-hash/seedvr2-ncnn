## 3. Real block class and topology

`NaMMSRTransformerBlock` execution order (real forward, not rewritten):

```text
vid/txt input
-> branch RMSNorm (attn_norm, no-affine)
-> AdaSingle attention input modulation
-> NaSwinAttention
    -> QKV projection (qkv_vid/qkv_txt Linear)
    -> Q/K RMSNorm per head (dim=head_dim=128)
    -> MM-RoPE3D (vid windowed, txt window-repeated)
    -> window packing -> per segment [vid_win; txt] -> varlen attention
    -> window reverse (vid) / txt window outputs mean merge
    -> attention output projection
-> AdaSingle attention output gate
-> attention residual
-> branch RMSNorm (mlp_norm)
-> AdaSingle MLP input modulation
-> SwiGLU (gate projection, up projection, SiLU(gate)*up, output projection)
-> AdaSingle MLP output gate
-> MLP residual
-> vid/txt output
```

RoPE (real `NaMMRotaryEmbedding3d`, MM-RoPE3D): configured rope_dim=128 -> effective rotary dim 126 (axis_dims=[42,42,42]), identity tail 2, T-major/W-fastest tokens, per-axis freq `theta^(-k/21)`; `vid_freqs[l:l+f, :h, :w]` with l = text length, f = post-patch frame count.

## 5. MLP hidden derivation

Real `SwiGLUMLP` (`models/dit_v2/mlp.py`): `hidden_dim = int(2 * dim * expand_ratio / 3)` then rounded up to a multiple of `multiple_of=256`. With the scaled config:

```text
2 * 512 * 4 / 3 = 1365.33 -> int -> 1365
256 * ceil(1365 / 256) = 256 * 6 = 1536
```

so `mlp_hidden_dim = 1536`, gate/up `[512 -> 1536]`, out `[1536 -> 512]`, all `bias=False`, SiLU via ncnn `swiglu_act` stage. The real 3B block uses the same formula: `2*2560*4/3 = 6826 -> 256*ceil(6826/256) = 256*27 = 6912` (matches Phase 11).

## 9. HybridDiTBlockRuntime design

`HybridDiTBlockRuntime` (host C++ + staged ncnn): ncnn runs the stable stages (RMSNorm, qkv Linear as dynamic Gemm, per-head q/k norm, rope_apply at fixed `q_max=128`, per-head varlen attention segments, attention/MLP projection Linears, SwiGLU gate/up/act/out); host C++ implements dynamic window partitioning/reassembly, txt repeat + mean merge, AdaSingle modulation/gates, residuals, and shape/validity checks. `ArtifactRegistry` metadata (`execution: "staged_dit_block"` + stage list) drives `read_dit_block()`; `NcnnModelCache` is path-keyed (19 models cached, reused across profiles and repetitions).

## 10. AdaSingle parity

Real `AdaSingle` math `out = hid*(scaleA+scaleB) + (shiftA+shiftB)` (in) / `out = hid*(gateA+gateB)` (out), emb `[B,6*C]` rearranged `b (d l g) -> b d l g` (l=2, g=3) -> per-dim `[attn_shift, attn_scale, attn_gate, mlp_shift, mlp_scale, mlp_gate]`. The runtime extracts exactly this layout. A reference-internal recompute (attn_norm + emb + params) reproduces the captured `ada_attn_in` bit-exactly (max 0.0), proving the runtime math is correct; the measured 1.9e-6..6.7e-6 deviation of the ncnn path is upstream RMSNorm FP32 noise (~5e-7) amplified by the modulation scale. `ada_*_in` gates use documented threshold 1e-5 (max observed 6.7e-6); `ada_attn_gate`/`ada_mlp_gate` pass at 1e-4 (max 4.8e-6).
