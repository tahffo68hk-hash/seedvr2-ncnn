# Decisions and gotchas

- Use flatten -> Gemm -> restore for PyTorch Linear mapping; direct 3-D InnerProduct was invalid.
- Use four heads + HostHeadMerge + projection; single-graph merge is blocked.
- Fixed RMS `valid_tokens=60` is a fidelity override; dynamic masks are key-only `-10000.f`.
- Dynamic RoPE uses local-window coordinates: theta=10000, rope_dim=6, axis_dims=[2,2,2], scales=[1,.01,.0001], fourth pair identity.
- `pnnx fp16=0` is required for FP32 parity; clean rebuild after public ABI changes.
- Metadata modes, not file existence, distinguish fixed/dynamic paths; no variant fallback.
- Phase 10 synthetic HD128 RoPE contract (historical regression, unchanged): rope_dim=128, theta=10000, axis_dims=[44,42,42] (even, sum 128), scales=[1,.01,.0001].
- Phase 10.1 real SeedVR2 MM-RoPE3D contract (Phase 10 READY): rotary-embedding-torch==0.5.3, SeedVR2 `e4de8c2`; configured rope_dim=128 -> `RotaryEmbedding(dim=42, freqs_for="lang", theta=10000)`; effective rotary dim 126 (axis_dims=[42,42,42]), identity tail 2, per-axis freq `theta^(-k/21)`, T/H/W axis-major, W-fastest tokens. Runtime metadata encodes `rope_dim=126` + `freq_mode="lang_rope"`; `freq_mode` is an optional general extension (default `"global_pairs"` keeps the legacy rope_dim=6 and synthetic contracts). Configured 128 is documentation-only (oracle manifest / JSON / docs).
- HD128 ncnn rope/mask Mats use the `Mat(w=64,h=64)` layout; the C=32 Phase 9.5 contract is untouched.
- Phase 12 synthetic staged DiT block (READY): `HybridDiTBlockRuntime` splits the real block into ncnn stages (RMSNorm, dynamic-Gemm Linear, per-head q/k norm, rope_apply at fixed `q_max=128` with pad + `-10000` mask + crop, per-head varlen segments, swiglu_act) and host logic (windowing, packing, txt repeat/mean merge, AdaSingle, residuals). qkv output is per-token `(o h d)` -> q/k/v are strided 512-wide slices of each 1536-wide row. q/k RMSNorm dim is per-head 128. Batch>1 packed q/k txt indexing follows the REAL `repeat_concat_idx`: `tgt_idx` references ORIGINAL per-sample txt offsets while q/k are the window-repeated rope outputs, so every window of sample b reuses repeated-txt rows `[cum_b, cum_b+l_b)`; v is not roped (original txt, per-window copies identical) and uses the advancing per-window copy. `ada_*_in` stages carry a documented 1e-5 threshold: the runtime math is bit-exact vs the reference inputs (recompute max 0.0) and the deviation is upstream RMSNorm FP32 noise (~5e-7) amplified by the modulation scale (measured max 6.7e-6). SwiGLU hidden = `256*ceil(int(2*C*expand/3)/256)` = 1536 for C=512 (real formula, 6912 for 2560).
- Phase 11 real single DiT block contract (READY, Phase 11.1): `NaMMSRTransformerBlock` (SeedVR2 `e4de8c2`) - flattened `[L,C]` tokens (video T-major W-fastest; text 1-D), per-window `[vid_win; txt]` varlen block-diagonal attention with txt repeated per window and mean-coalesced outputs, `vid_freqs[l:l+f, :h, :w]` (l = text length, f = post-patch frame count), AdaSingle emb 6*dim split shift/scale/gate per attn/mlp, SwiGLU hidden round-up to multiple of 256 (2560->6912), pre-norm residual with post-attention/MLP gate. The real block forward (158,633,472 params) executes in the isolated conda env `seedvr2-block-probe` (torch 2.4.0+cpu). flash_attn/apex (fused CUDA) are replaced in the TEST HARNESS ONLY by `tests/seedvr2_dit_block_contract/compat/` CPU math-equivalent modules (parity < 1e-6); CUDA/Apex fused-kernel fidelity is NOT validated. Real `get_freqs` txt branch has a pre-existing shape quirk: `txt_freqs[:l].repeat(1,3)` only broadcasts cleanly for batch=1 (l==1); for batch>1 the expected per-window freqs must be computed as `txt_full[:l].repeat(1,3).reshape(-1,eff)`. Last-layer (`is_last_layer=True`) txt is never consumed by MLP/ada, so the final residual doubles it: `txt_out == 2*(proj_out + txt_in)` exactly. `rope.get_axial_freqs` is `lru_cache`d - probe harness clears it per block. Do not modify third_party/SeedVR2; do not use a hand-written substitute for the real block forward.

- Phase 13 real-width staged block (READY): real 3B config C=2560/H=20/HD=128/MLP 6912, seed 20260803, random weights. The runtime is metadata-driven - only the variant metadata and tests were added, no duplicated runtime. qk-norm RMSNorm weights in the real state dict are all-ones, so pnnx emits no-affine RMSNorm with 0-byte bins (`pnnx_folded_identity_weight=true` in the inventory manifest); a weighted stage with an empty bin and no fold marker is a broken export. The 20 attention heads share ONE weight-free `head` model (cache 19). AdaSingle has no trainable parameters (runtime-only, consumes `emb`); do not invent AdaLN projections. Last-layer = base parameter set minus 9 txt-side MLP/AdaSingle entries, control-flow only, reuses all 19 models. Large artifacts NEVER enter Git: `.phase13_local_artifacts/` and `.phase13_export_tmp/` are exactly ignored; use `check_no_large_tracked_artifacts.py` before commit; explicit-path `git add` only. 32-block all-resident FP32 ~20.1 GB / FP16 ~10.0 GB (estimate) -> per-block streaming is required for mobile; Pad 7 Pro / Android/Vulkan NOT validated.

- Phase 14 real-weight hybrid milestone (READY): the official `ByteDance-Seed/SeedVR2-3B` checkpoint was task-authorized and downloaded (5/5 sha256 verified, `official_source_only=true`, `mirror_used=false`, main `seedvr2_ema_3b.pth` = `6bcc5ac5...`), loaded with `torch.load(weights_only=True, mmap=True, map_location=cpu)` (no fallback). Mandatory gate that flipped the phase: real qk-norm RMSNorm weights are NOT all-ones -> `REAL_AFFINE_REQUIRED`; real affine bins were exported and Phase 13 0-byte bins are FORBIDDEN for real weights. Adapter contract: ncnn mode must print `HYBRID BLOCK EXECUTED`, enforce `ncnn_adapter_call_count>0` and `original_block_call_count==0`, and abort (never silently fall back to PyTorch). Visual outputs/large tensors only in git-ignored `.phase14_local_checkpoint/`, `.phase14_local_artifacts/`, `.phase14_visual_outputs/`, `.phase14_export_tmp/`.

- Phase 15 streaming (READY): per-block strict lifecycle `LOAD -> EXECUTE -> UNLOAD` with runtime destroyed, cache cleared to 0, resident bytes 0, and artifact file rename-probes passing; `max_resident_weighted_blocks=1` always. Streaming and resident final outputs are bit-identical (chain parity 8.872e-9 .. 3.777e-6 relative). Streaming memory stays flat (474/496/476 MB) vs resident linear growth (446/839/1530 MB) - per-block streaming is the required 32-block strategy. Adapter binding: declared block index must be in 0..30 and match artifact metadata `block.block_index`.

- Phase 16 full DiT streaming (READY): the whole 32-block chain runs through ncnn one block at a time; blocks 0..9 split 29-key layout vs blocks 10..31 shared 15-key `.all.` layout (derived from the checkpoint, never hardcoded); last layer 31 runs at most once as the final block. Chain limits are per-chain (1e-2 / 2e-2 / 5e-2 for 8/16/full); the 1e-3 single-block budget is the Phase 14/15 criterion only. The official `vid_out_ada` head modulation reuses the shared cache key `emb_repeat_0_vid` (cache keys only carry `idx` + `branch_tag`, not layer/mode); with the whole chain replaced by ncnn the visual harness must rebuild that weight-independent entry exactly (einops `l=2,g=3` + repeat by `vid_len`) before the head executes. Error growth E1..Efull is not monotonic - it is dominated by the block-16 anchor and the last-layer head path, not by raw chain length.
