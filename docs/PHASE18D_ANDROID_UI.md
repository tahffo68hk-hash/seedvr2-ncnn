# Phase 18D Android user workflow shell

The Pad 7 Pro build now presents a normal user workflow instead of a JNI diagnostic page: local-processing home, system document picker, private input copy with EXIF rotation, image preview, balanced/low-temperature/experimental performance choices, a labelled UI DEMO run page, cancellation, a side-by-side test result page, and MediaStore saving to `Pictures/SeedEdge/`.

The UI DEMO is deliberately not model execution. Its result is the selected input preview copied to PNG and the result page says this is a test sample, not a complete SeedVR2 enhancement. The normal button cannot read a Block32 checkpoint. Real runtime status remains `PARTIAL`; Android image enhancement remains `NOT READY` until a selected photo traverses real VAE encoder, 32 DiT blocks, scheduler and VAE decoder.

Pad evidence is in `reports/phase18d_ui_device_validation.json`, `phase18d_photo_picker.json`, and `phase18d_gallery_save.json`.
